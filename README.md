# GEFEST Service AI

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![Machine Learning](https://img.shields.io/badge/Machine%20Learning-MLP-green)
![scikit-learn](https://img.shields.io/badge/scikit--learn-MLPRegressor-orange)

![Status](https://img.shields.io/badge/status-ready-success)

**GEFEST Service AI** — учебная интеллектуальная система для прогнозирования длительности ремонта компьютерного оборудования.

Программа использует простую нейронную сеть типа **MLP — Multilayer Perceptron**, которая анализирует параметры оборудования и ремонтной заявки, после чего рассчитывает ожидаемую продолжительность ремонта в часах.

Проект разработан в рамках технологической практики и демонстрирует практическое применение методов машинного обучения для задач технического обслуживания оборудования.

---

## Возможности программы

Приложение позволяет:

- прогнозировать длительность ремонта оборудования;
- учитывать возраст оборудования;
- учитывать количество предыдущих ремонтов;
- учитывать сложность неисправности;
- учитывать наличие необходимых запасных частей;
- учитывать приоритет ремонтной заявки;
- рассчитывать рекомендуемый резерв рабочего времени;
- просматривать демонстрационную обучающую выборку;
- изучать логику работы нейронной сети;
- просматривать архитектуру модели;
- анализировать показатели качества модели;
- отображать график изменения функции потерь;
- сохранять историю выполненных прогнозов;
- экспортировать историю расчётов в CSV.

---

## Интерфейс

Программа имеет графический интерфейс и состоит из нескольких функциональных разделов:

### Прогноз

Основное рабочее окно приложения.

Пользователь вводит:

- возраст оборудования;
- количество предыдущих ремонтов;
- сложность неисправности;
- наличие запасных частей;
- приоритет заявки.

После обработки данных нейронная сеть рассчитывает ожидаемую длительность ремонта.

Также система автоматически формирует рекомендуемый резерв времени.

---

### Данные

Раздел содержит фрагмент демонстрационного набора данных, используемого для обучения модели.

В выборке представлены следующие параметры:

| Признак | Описание |
|---|---|
| `age_years` | возраст оборудования |
| `previous_repairs` | количество предыдущих ремонтов |
| `complexity` | сложность неисправности от 1 до 10 |
| `parts_available` | наличие необходимых запчастей |
| `priority` | приоритет ремонтной заявки |
| `repair_hours` | фактическая длительность ремонта |

В текущей версии автоматически формируется **720 демонстрационных наблюдений**.

Данные создаются программно и не содержат конфиденциальной информации предприятия.

## Логика работы

Обработка одной заявки выполняется в несколько этапов.

### 1. Ввод исходных данных

Пользователь задаёт характеристики оборудования и ремонтной заявки.

### 2. Подготовка данных

Числовые параметры преобразуются с помощью:

```python
StandardScaler
```

Это приводит признаки к сопоставимому масштабу и улучшает процесс обучения нейронной сети.

### 3. Нейросетевое прогнозирование

Подготовленные значения передаются в многослойный персептрон.

Архитектура модели:

```text
5 входных параметров
        ↓
18 нейронов
        ↓
10 нейронов
        ↓
1 выход
```

Или в сокращённом виде:

```text
5 → 18 → 10 → 1
```

### 4. Получение результата

Нейронная сеть возвращает прогнозируемую длительность ремонта в часах.

Дополнительно программа рассчитывает резерв:

```text
резерв = прогнозируемое время + 15 %
```

---

## Нейронная сеть

В проекте используется класс:

```python
MLPRegressor
```

из библиотеки:

```python
scikit-learn
```

Основные параметры модели:

| Параметр | Значение |
|---|---|
| Входных признаков | 5 |
| Скрытых слоёв | 2 |
| Первый скрытый слой | 18 нейронов |
| Второй скрытый слой | 10 нейронов |
| Выходов | 1 |
| Функция активации | ReLU |
| Оптимизатор | Adam |
| Learning rate | 0.0025 |
| Validation fraction | 0.15 |
| Early stopping | включён |
| Максимальное число итераций | 4000 |

---

## Результаты обучения

Набор данных автоматически разделяется на обучающую и тестовую части в соотношении:

```text
80 % — обучение
20 % — тестирование
```

При 720 наблюдениях:

```text
Обучающая выборка: 576
Тестовая выборка: 144
```

На текущей версии модели получены следующие результаты:

| Метрика | Значение |
|---|---:|
| MAE | ≈ 1.34 часа |
| RMSE | ≈ 1.66 часа |
| R² | ≈ 0.958 |
| Итераций обучения | ≈ 153 |

Значение:

```text
R² ≈ 0.958
```

показывает, что модель достаточно хорошо описывает зависимость между исходными параметрами и длительностью ремонта в рамках сформированной демонстрационной выборки.

## График обучения

В приложении автоматически отображается **кривая функции потерь**.

Во время обучения значение ошибки постепенно уменьшается, что позволяет визуально оценить процесс обучения модели.

В одном из тестовых запусков функция потерь уменьшилась приблизительно:

```text
0.503 → 0.017
```

## Формирование обучающей выборки

Для демонстрации работы системы используется искусственно сформированный набор данных.

Продолжительность ремонта зависит от нескольких факторов:

```text
возраст оборудования
+
история предыдущих ремонтов
+
сложность неисправности
+
наличие запасных частей
+
приоритет заявки
```

Дополнительно к результату добавляется небольшое случайное отклонение, благодаря чему обучающая выборка имеет более реалистичный характер.

Такой способ формирования данных позволяет демонстрировать принципы машинного обучения без использования внутренних или конфиденциальных данных организации.
